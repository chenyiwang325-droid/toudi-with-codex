填报资料与设置

填写自己的资料，再回到招聘网页识别与填写。

个人资料

按模块填写。没有的内容留空，教育、工作、项目、在校经历、获奖与论文可逐段添加。

填写要求

保留每次填报需要遵循的资料口径和个人要求。

尚未保存额外填写要求。

填写使用已确认的完整资料。补充规则供自己的 Agent 参考。

Agent 协作

选择自己的协作方式与模型。网页先自动识别；需要时点击“Agent 核对”，查看结果后再点击“自动填写”。

协作方式

推荐本机 Codex 与 Luna；核对使用 ChatGPT 登录的现有额度。

本机 Codex 连接

检查连接后，从当前客户端的模型目录选择。

核对模型

推荐 gpt-6-luna。只从实际目录选择；不可用时保留计划，不更换模型。

  1. 在招聘网页点击「自动填写」，建立当前网页的对应资料。
  2. 在下方「补充任务」复制匹配任务，交给自己的 Agent。
  3. 将返回的 JSON 粘贴到下方，导入后应用到当前网页。

无需本机连接工具。使用哪个 Agent、模型与账号由你决定；费用按你已有工具的使用方式确定。

尚未配置 Agent；本地识别与填写可用。

核对只使用当前字段、网页实际选项及对应的非敏感资料。固定内容按完整原文填写；主观回答可在下方补充任务中生成并编辑。

补充任务展开

为最近处理的招聘网页补充匹配或主观回答。外部 Agent 返回已有资料键与网页选项，不修改资料原文。

主观回答

首次连接 Codex展开收起
  1. 运行浏览器工具包中的「TouDi 浏览器连接」安装程序一次。
  2. 安装官方 Codex 客户端，并使用自己的 ChatGPT 账号登录。
  3. 选择「本机 Codex」，检查连接，选择模型并保存协作设置。

Chrome 按需启动连接工具，日常无需打开中控台或终端。不需要 API Key 或新增模型服务；模型核对使用现有 Codex 额度。
