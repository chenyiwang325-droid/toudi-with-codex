填报资料与设置

个人资料

按模块填写。没有的内容留空，教育、工作和项目可以添加多段。

填写要求

保留每次填报需要遵循的资料口径和个人要求。

尚未保存额外填写要求。

日期精度、经历归属、选项和长度由表单引擎检查；新增的自然语言规则需要在填写计划中人工核对。

Agent 协作

首次选择自己的协作方式与模型，之后在这里调整。明确字段始终先用本地规则匹配。

协作方式

Codex 可直接核对；其他 Agent 使用复制任务、导入结果。

本机 Codex 连接

检查连接后，从当前客户端的模型目录选择。

核对模型

由你指定；不可用时保留原计划，不替换模型。

识别后自动核对

开启后仅对歧义字段调用所选模型，消耗现有 Codex 额度。

  1. 在招聘网页点击插件，先识别并查看填写计划。
  2. 点击「复制匹配任务」，交给自己正在使用的 Agent。
  3. 将返回的 JSON 粘贴到插件，点击「导入并重新核对」。

无需本机连接工具。使用哪个 Agent、模型与账号由你决定；费用按你已有工具的使用方式确定。

尚未配置 Agent；本地识别与填写可用。

字段核对只发送字段说明与候选资料键。主动生成主观题草稿时，会把所选资料版本的相关经历内容交给你指定的 Agent，并排除身份、联系方式、家庭信息及标为敏感的字段；草稿经你采纳后才进入填写计划。连接检查不发起生成。

首次连接 Codex展开收起
  1. 运行浏览器工具包中的「TouDi 浏览器连接」安装程序一次。
  2. 安装官方 Codex 客户端，并使用自己的 ChatGPT 账号登录。
  3. 选择「本机 Codex」，检查连接，选择模型并保存协作设置。

Chrome 按需启动连接工具，日常无需打开中控台或终端。不需要 API Key 或新增模型服务；模型核对使用现有 Codex 额度。
