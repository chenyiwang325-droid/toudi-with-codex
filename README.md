# 与自己的 Agent 协作的求职工作台

求职资料往往散在表格、网页、准备稿和面试记录里。**TouDi 把投递记录、公司准备、通用题库、岗位探查与复盘组织到同一个工作台**，让你能找到材料、保留判断，并把下一次准备建立在已有积累上。

你确定信源、真实资料与本次目标；自己选用的 Agent 在外部工具中核对、整理、更新；工作台负责保存、阅读、标记与复用。每个任务有独立流程，是否继续下一步由你决定。

A job-search workbench for collaborating with your own Agent: organize applications, preparation, research and interview reviews. Local editing; encrypted read-only access on mobile.

## 能完成什么

| 你要做的事 | Agent 与工作台如何配合 | 留下的结果 |
|---|---|---|
| 更新投递记录 | Agent 按指定信源核对新增与变化；工作台保留独立的进度、收藏、不适合和备注 | 可筛选的记录、变更说明、已有标记 |
| 准备一场面试 | 公司背景与 JD 前置；专项问题独立组织主答与备答；通用项目、STAR 与行为题继续复用 | 公司准备稿、关联阅读条目、通用题库 |
| 了解公司与岗位 | 先核对主体、岗位与日期，分开呈现事实、待遇线索、口碑与未知项 | 公司主报告、证据目录、可读附件 |
| 复盘一场面试 | 还原原问答与追问，先看全场要点；到位回答保留，实质缺口才改进 | 完整复盘场次、重点改进；按明确请求内化目标条目 |
| 在手机复习 | 从同一份本地资料构建加密副本，按用户授权发布 | 可解锁的只读工作台与按需附件 |

日常页面提供表格、看板和统计；左侧统一搜索筛选，固定总览计数，冻结标记与名称列。准备可跨当前通用/公司模式检索正文，定位独立题目、主答与备答；探查通过目录查找公司并阅读报告和证据附件；复盘按公司、岗位和轮次定位，阅读原答、追问与分析。各模块保留可收起目录与独立阅读区。浅色、深色、系统主题与阅读偏好可调整。

## 看一轮协作

例如准备一场面试：你提供 JD、公司信源与真实经历，Agent 先核对本场范围，把公司背景与 JD 前置，再组织公司专项主答与备答；已有通用项目与行为题继续复用。核对内容和公司关联后导入，你在工作台展开题目、阅读备答并回到通用准备复习。**公司专项与通用积累各自维护，下一次准备不用重新开始。**

## 三步开始

**1. 下载并启动。** Python 3.10+，macOS/Linux；本地工作台不需要前端构建或额外 Python 包。

```sh
git clone https://github.com/chenyiwang325-droid/toudi-workbench.git
cd toudi-workbench
python3 run.py
```

打开 http://127.0.0.1:8327/ 。首次下载是空工作台，你的资料放在 `runtime/` 或指定的仓库外工作区。

**2. 给自己的 Agent 提供信源、资料和明确任务。** 复制下面的话术，补齐花括号内容：

```text
请在我的环境中维护 TouDi 工作台。
仓库目录：{下载目录}；资料工作区：{资料目录}。
先读取 AGENTS.md、docs/流程协作.md、docs/内容与渲染契约.md。
我的信源是{网址/文件/可用工具}，真实资料是{简历/JD/经历目录}。
本次只执行{任务与明确范围}。先核对资料缺口，再生成候选、
核对变更、保留无关标记与正文，更新后检查实际工作台。
不要自动扩展到网申、联系、问答库内化或公开发布。
手机同步的口令、托管目标与发布范围由我另行指定。
```

**3. 在工作台核对结果，继续使用。** 检查本次记录或材料、来源与未覆盖项；标记进度、阅读准备、记录复盘。需要新增流程时，再给 Agent 一个明确任务。

记录信源适配由你的 Agent 完成；仓库提供规范记录发布与材料解析脚本，接入过程不依赖作者的私有 Skill。没有默认抓取网站或特定作者的投递判断。具体输入、命令、校验和恢复方式见[流程协作](docs/流程协作.md)。

## 本地使用与手机阅读

- **本地可写：** 通用准备与复盘可以在页面编辑；投递标记独立保存。公司准备以 Markdown 为母本，Agent 更新后导入，网页用于阅读。并发修改会提示冲突，避免覆盖另一份更新。
- **手机只读：** 口令解锁加密快照，阅读记录、准备、探查和复盘；修改请回本地。公开网页不能仅凭一段路径读取你的本机目录。
- **由你控制资料与发布：** GitHub 分发空源码与匿名展示；个人资料、附件、口令和凭据不入仓库。Cloudflare 只上传自己的快照输出目录，目标由用户指定。

快照需要安装 `requirements.txt`。PDF 文本提取为可选系统依赖；Windows 可使用 Linux 环境，原生文件锁暂不支持。[首次使用与部署](docs/首次使用与部署.md)说明工作区、附件、快照与托管步骤。
