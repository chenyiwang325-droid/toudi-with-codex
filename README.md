# TouDi / 投递中控台

**TouDi 是与自己的 Agent 协作的个人求职工作台。** 它集中管理投递记录、面试准备、岗位探查和面试复盘，让岗位进度与相关资料可以在同一处查看、更新和复习。

推荐由投递 Agent 整理信源和材料，按任务更新工作台；你也可以手动添加资料、编辑内容或通过文件导入。项目支持部署为自己的在线工作台，登录网址后即可使用；资料保存在你的部署实例中。也支持本地运行，以及单独部署加密阅读版。

[主要功能](#主要功能) · [Agent 协作](#agent-协作) · [界面预览](#界面预览) · [开始使用](#开始使用) · [文档](#文档)

## 主要功能

| 功能 | 可以做什么 |
| --- | --- |
| **投递管理** | 查看岗位与截止日期，筛选目标公司，维护投递进度、收藏、适合与否及备注；在表格、看板和统计间切换。 |
| **面试准备** | 分开管理通用准备与公司专项；按公司查阅背景、JD 和问答，搜索材料，展开主答与备答。 |
| **岗位探查** | 汇集公司与岗位报告，查看依据、附件和待核实事项，辅助投递判断。 |
| **面试复盘** | 按公司、岗位和轮次整理面试，查看全场要点、原问答与追问，记录分析和改进。 |

在线工作台支持编辑和保存，阅读设置包含浅色与深色主题、显示密度和求职偏好。需要单独的阅读入口时，可将加密快照部署到自己的 Cloudflare Pages。

## Agent 协作

**你提供信源、材料和任务，Agent 负责整理与更新，工作台保存结果。** 在常用的 Agent 工具中发出请求，它会读取仓库内的流程与内容规范，拉取当前资料，完成相应任务，再将修改同步到对应模块。

![协作流程：你向自己的 Agent 提供信源、材料和任务；Agent 按需更新记录、探查岗位、准备面试或整理复盘；结果进入投递中控台。也可手动编辑或通过文件导入。](docs/assets/agent-workflow.svg)

每次可以单独安排一项工作，例如“更新这批岗位并保留原标记”“根据这份 JD 准备面试”或“复盘这场面试”。你在工作台中查看结果，再提出补充或修改要求。

## 开始使用

### 1. 部署自己的在线工作台

**推荐部署到自己的云端账号，获得一个可登录、可编辑的网址。** 仓库提供 Render 部署配置，网页和资料服务一起运行，持久磁盘保存个人资料。

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/chenyiwang325-droid/toudi-workbench)

点击部署按钮，在托管平台设置访问密码，确认服务与存储配置；完成后打开平台提供的 HTTPS 网址并登录。该配置使用带持久磁盘的付费服务，费用以平台创建页面为准。具体设置见[云端部署](docs/云端部署.md)。

### 2. 接入自己的 Agent

**把工作台网址、信源、材料和本次任务交给你的投递 Agent。** Agent 授权凭据在自己的运行环境中配置，网页设置中可复制接入说明。

```text
请帮我使用 TouDi 管理求职资料。
工作台网址：{我的 HTTPS 网址}
仓库位置：{代码目录，或请从 GitHub 下载}
信源：{招聘网站、文件或可用的数据来源}
个人材料：{简历、JD、项目经历或面试记录}
本次任务：{要处理的公司、岗位或场次，以及需要的结果}

请先读取仓库 AGENTS.md、docs/云端部署.md、docs/流程协作.md
和 docs/内容与渲染契约.md。先拉取最新资料，按对应流程整理，
只同步本次改动，保留无关内容与已有标记，并核对网页结果。
```

### 3. 在网页查看和维护

**日常使用直接打开自己的网址。** 在表格中更新进度与标记，在准备、探查和复盘模块查阅资料；网页修改保存在同一实例中。新增内容可继续交给 Agent 整理，也可通过原有文件流程手动维护。

### 手动维护

**不使用 Agent 也可以维护资料。** 通用准备支持在网页新增和编辑；投递记录支持修改进度、标记、备注及详情字段；已有复盘支持编辑问答与分析。新增招聘记录、公司准备稿、探查报告和复盘稿通过规范文件与命令导入，具体步骤见[手动使用说明](docs/首次使用与部署.md#手动使用)。

## 部署方式

| 方式 | 适合用途 | 使用方式 |
| --- | --- | --- |
| **在线工作台（推荐）** | 日常管理、网页编辑、跨设备查阅和 Agent 协作 | 登录自己部署的 HTTPS 网址，资料保存在持久工作区。 |
| 本地工作台 | 希望资料保留在自己的电脑，或进行开发 | 按[本地运行说明](docs/首次使用与部署.md#本地运行可选)启动。 |
| Cloudflare 加密阅读版 | 单独分享给自己、在手机上只读查阅 | 部署加密快照，使用访问口令解锁。 |

在线版面向一个使用者的独立实例。代码与个人资料分开保存，更新仓库代码不会替换个人资料；服务更新由实例所有者决定。
