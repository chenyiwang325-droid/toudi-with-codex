# TouDi / 投递中控台

**TouDi 是与自己的 Agent 协作的个人求职工作台。** 它集中管理投递记录、面试准备、岗位探查和面试复盘，让岗位进度与相关资料可以在同一处查看、更新和复习。

推荐由投递 Agent 整理信源和材料，按任务更新工作台；你也可以手动维护内容或通过规范文件导入。当前可由 Agent 在自己的材料环境中管理，再将加密阅读站免费部署到 Cloudflare，获得跨设备查阅的网址。需要跨设备直接编辑时，也支持独立托管完整工作台。

[主要功能](#主要功能) · [Agent 协作](#agent-协作) · [界面预览](#界面预览) · [开始使用](#开始使用) · [文档](#文档)

## 主要功能

| 功能 | 可以做什么 |
| --- | --- |
| **投递管理** | 查看岗位与截止日期，筛选目标公司，维护投递进度、收藏、适合与否及备注；在表格、看板和统计间切换。 |
| **面试准备** | 分开管理通用准备与公司专项；按公司查阅背景、JD 和问答，搜索材料，展开主答与备答。 |
| **岗位探查** | 汇集公司与岗位报告，查看依据、附件和待核实事项，辅助投递判断。 |
| **面试复盘** | 按公司、岗位和轮次整理面试，查看全场要点、原问答与追问，记录分析和改进。 |

完整工作台支持编辑和保存，阅读设置包含浅色与深色主题、显示密度和求职偏好。Cloudflare 加密阅读站用于查阅最近一次发布的资料，不能写回；具体操作范围见[手动使用说明](docs/首次使用与部署.md#手动使用)。

## Agent 协作

**你提供信源、材料和任务，Agent 负责整理与更新，工作台保存结果。** 在常用的 Agent 工具中发出请求，它会读取仓库内的流程与内容规范，读取最新资料，完成相应任务，再保存到对应模块；需要在线查阅时按授权发布加密阅读站。

![协作流程：你向自己的 Agent 提供信源、材料和任务；Agent 按需更新记录、探查岗位、准备面试或整理复盘；结果进入投递中控台。也可手动编辑或通过文件导入。](docs/assets/agent-workflow.svg)

每次可以单独安排一项工作，例如“更新这批岗位并保留原标记”“根据这份 JD 准备面试”或“复盘这场面试”。你在工作台中查看结果，再提出补充或修改要求。

## 开始使用

### 1. 选择使用方式

**建议从“Agent 管理 + 免费在线查阅”开始。** 完整工作台在自己的 Agent 材料环境中保存和编辑；需要跨设备查阅时，只将加密产物部署到自己的 Cloudflare Pages。复用常用 Agent，无需另购模型 API、服务器或域名。步骤与费用边界见[使用方案](docs/使用方案.md)和[免费阅读站部署](docs/首次使用与部署.md#部署到自己的-cloudflare-pages)。

如果需要立即在不同设备编辑同一份资料，可以将现有 Python 后端部署到已有服务器，或选用付费托管。操作见[完整在线部署](docs/云端部署.md)。后续优先适配 Cloudflare 单平台的免费编辑方案；该版本尚未实现，当前免费阅读站仍为只读。

### 2. 接入自己的 Agent

**把使用方式、信源、材料和本次任务交给你的投递 Agent。** 首次环境配置和发布步骤由 Agent 处理；账号登录、资料授权和不确定的业务事实由你确认。

```text
请帮我使用 TouDi 管理求职资料。
使用方式：{Agent 管理并发布加密阅读站，或完整在线实例}
仓库位置：{代码目录，或请从 GitHub 下载}
信源：{招聘网站、文件或可用的数据来源}
个人材料：{简历、JD、项目经历或面试记录}
本次任务：{要处理的公司、岗位或场次，以及需要的结果}
已有工作区或网址：{如已有，请提供；否则请建立独立工作区}
在线发布目标：{需要发布时提供自己的 Cloudflare 项目或托管实例}

请先读取仓库 AGENTS.md、docs/使用方案.md、docs/流程协作.md
和 docs/内容与渲染契约.md。检查环境并读取最新母本，按对应流程
处理本次任务，保留无关内容与已有标记，核对实际网页和附件。
阅读站只发布加密产物；完整在线实例先拉取最新版本，再同步变更。
凭据留在受控环境，不把我的资料或密文提交到公开仓库。
```

### 3. 在网页查看和维护

**查阅直接打开自己的网址，新增与整理继续交给 Agent。** 免费阅读站显示最近一次成功发布的内容；手动编辑在完整工作台完成，再由 Agent 构建并更新阅读站。完整在线实例中的网页修改直接保存在该实例，Agent 后续任务先读取这些修改。

已有 Agent 继续使用原来的信源、录音和材料工具。每次任务按“读取最新母本 → 执行与校验 → 保存 → 必要时发布 → 网页验收”完成，具体见[日常协作](docs/使用方案.md#日常协作)。

### 手动维护

**不使用 Agent 也可以维护资料。** 通用准备支持在网页新增和编辑；投递记录支持修改进度、标记、备注及详情字段；已有复盘支持编辑问答与分析。新增招聘记录、公司准备稿、探查报告和复盘稿通过规范文件与命令导入，具体步骤见[手动使用说明](docs/首次使用与部署.md#手动使用)。

## 部署方式

| 方式 | 适合用途 | 使用方式 |
| --- | --- | --- |
| **Agent 管理 + Cloudflare 加密阅读站（推荐起步）** | 完整工作台管理，网站跨设备查阅 | 原工作区保存资料，免费方案内发布加密快照，使用口令解锁；阅读站只读。 |
| 完整在线工作台（可选） | 跨设备网页编辑和 Agent 同步 | 复用已有服务器或采用付费托管，登录自己的 HTTPS 网址。 |
| 本地工作台 | 不需要在线入口，或进行开发 | 按[本地运行说明](docs/首次使用与部署.md#本地运行可选)启动，无需托管账号。 |

完整在线版面向一个使用者的独立实例。代码与个人资料分开保存，更新仓库代码不会替换个人资料；服务更新由实例所有者决定。Cloudflare 完整编辑版的后续方案见[使用方案](docs/使用方案.md#完整网页编辑的后续方案)，当前尚未提供部署入口。
