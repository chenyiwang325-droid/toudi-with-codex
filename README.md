# TouDi / 投递中控台

**TouDi 是与自己的 Agent 协作的个人求职工作台。** 它集中管理投递记录、面试准备、岗位探查和面试复盘，让岗位进度与相关资料可以在同一处查看、更新和复习。

推荐由投递 Agent 整理信源和材料，按任务更新工作台；你也可以手动维护内容或通过规范文件导入。网页与 Agent 使用同一份可写资料，用户配置和业务修改保存到自己的工作区。项目支持现有 Python 服务的本地或在线运行，完整 Cloudflare 编辑版尚未实现。

当前网页支持标记、求职偏好、通用准备及已有复盘的编辑保存；新增原始记录、公司准备和探查正文仍通过文件流程维护。完整网页管理的缺口与保存范围见[编辑与保存](docs/编辑与保存.md)。

## 主要功能

| 功能 | 可以做什么 |
| --- | --- |
| **投递管理** | 查看岗位与截止日期，筛选目标公司，维护投递进度、收藏、适合与否及备注；在表格、看板和统计间切换。 |
| **面试准备** | 分开管理通用准备与公司专项；按公司查阅背景、JD 和问答，搜索材料，展开主答与备答。 |
| **岗位探查** | 汇集公司与岗位报告，查看依据、附件和待核实事项，辅助投递判断。 |
| **面试复盘** | 按公司、岗位和轮次整理面试，查看全场要点、原问答与追问，记录分析和改进。 |

阅读设置包含浅色与深色主题、显示密度和求职偏好。显示设置目前保存在当前浏览器，求职偏好与标记通过服务保存到工作区。Cloudflare 加密阅读站只用于附加查阅，不能写回；具体操作范围见[手动使用说明](docs/首次使用与部署.md#手动使用)。

## Agent 协作

**你提供信源、材料和任务，Agent 负责整理与更新，工作台保存结果。** 在常用的 Agent 工具中发出请求，它会读取仓库内的流程与内容规范，读取最新资料，完成相应任务，再保存到对应模块；需要在线查阅时按授权发布加密阅读站。

![协作流程：你向自己的 Agent 提供信源、材料和任务；Agent 按需更新记录、探查岗位、准备面试或整理复盘；结果进入投递中控台。也可手动编辑或通过文件导入。](docs/assets/agent-workflow.svg)

每次可以单独安排一项工作，例如“更新这批岗位并保留原标记”“根据这份 JD 准备面试”或“复盘这场面试”。你在工作台中查看结果，再提出补充或修改要求。

## 开始使用

### 1. 建立可写工作区

**管理与编辑使用可写工作台，网页和 Agent 共用正式资料。** 当前可在自己的材料环境启动 Python 服务，或复用已有服务器部署在线实例；首次环境配置可交给 Agent。操作见[首次使用与部署](docs/首次使用与部署.md)和[在线部署](docs/云端部署.md)。

**后续优先采用 Cloudflare 单平台的完整可写方案，在免费额度内运行。** 它需要可写接口、持久存储和各模块编辑入口；当前尚未实现。只将 HTML 部署为静态网站不能保存到工作区，加密阅读站也不能替代管理功能。当前能力、实施范围与费用边界见[使用方案](docs/使用方案.md)。

### 2. 接入自己的 Agent

**把使用方式、信源、材料和本次任务交给你的投递 Agent。** 首次环境配置和发布步骤由 Agent 处理；账号登录、资料授权和不确定的业务事实由你确认。

```text
请帮我使用 TouDi 管理求职资料。
使用方式：{可写本地工作区或在线实例；加密阅读站为可选附加入口}
仓库位置：{代码目录，或请从 GitHub 下载}
信源：{招聘网站、文件或可用的数据来源}
个人材料：{简历、JD、项目经历或面试记录}
本次任务：{要处理的公司、岗位或场次，以及需要的结果}
已有工作区或网址：{如已有，请提供；否则请建立独立工作区}
在线发布目标：{需要发布时提供自己的 Cloudflare 项目或托管实例}

请先读取仓库 AGENTS.md、docs/使用方案.md、docs/流程协作.md
和 docs/内容与渲染契约.md。检查环境并读取最新母本，按对应流程
处理本次任务，保留无关内容与已有标记，核对实际网页和附件。
阅读站只发布加密产物；完整在线实例先拉取最新版本，再同步变更。
凭据留在受控环境，不把我的资料或密文提交到公开仓库。
```

### 3. 在网页查看和维护

**支持的网页修改保存到同一个工作区，Agent 后续任务读取这些修改。** 现有网页入口与文件导入范围见[编辑与保存](docs/编辑与保存.md#当前功能核对)。加密阅读站只显示最近一次发布的内容，不能执行管理和保存操作。

已有 Agent 继续使用原来的信源、录音和材料工具。每次任务按“读取最新母本 → 执行与校验 → 提交保存 → 读回与网页验收”完成；只有使用附加阅读站时才另行构建和发布快照。具体见[日常协作](docs/使用方案.md#日常协作)。

### 手动维护

**不使用 Agent 也可以维护资料。** 通用准备支持在网页新增和编辑；投递记录支持修改进度、标记、备注及详情字段；已有复盘支持编辑问答与分析。新增招聘记录、公司准备稿、探查报告和复盘稿通过规范文件与命令导入，具体步骤见[手动使用说明](docs/首次使用与部署.md#手动使用)。

## 部署方式

| 方式 | 适合用途 | 使用方式 |
| --- | --- | --- |
| **Python 在线实例** | 当前已支持的网页编辑、跨设备保存和 Agent 同步 | 复用已有服务器或选择托管，登录自己的 HTTPS 网址；全部网页入口尚待补齐。 |
| 本地工作台 | 在自己的材料环境管理与保存，或进行开发 | 按[本地运行说明](docs/首次使用与部署.md#本地运行可选)启动，无需托管账号。 |
| Cloudflare 加密阅读站 | 附加跨设备查阅 | 免费方案内发布加密快照，使用口令解锁；只读，不作为管理入口。 |

完整在线版面向一个使用者的独立实例。代码与个人资料分开保存，更新仓库代码不会替换个人资料；服务更新由实例所有者决定。Cloudflare 完整编辑版的后续方案见[使用方案](docs/使用方案.md#完整网页编辑的后续方案)，当前尚未提供部署入口。
