# 设置设计规范

**设置复用现有工作台视觉系统，只保留有实际用途的选项。** 外观、求职偏好、资料管理、初始化与协作四类各有明确边界；部署工具不进入日常设置。

## 统一组件

| 元素 | 桌面标准 |
| --- | --- |
| 页面标题 | 24px / 32px，600 字重 |
| 分区标题 | 16px / 24px，600 字重 |
| 设置名称 | 14px / 20px，600 字重 |
| 控件与正文 | 13px / 20px |
| 辅助说明 | 12px / 20px，使用次级文字色 |
| 普通设置行 | 80px；名称与短说明在左，控件在右 |
| 控件 | 36px；统一圆角、字体、边框与焦点显示 |
| 控件列 | 320px；较窄窗口 270px |
| 列间距 | 24px；较窄窗口 20px |
| 展开入口 | 48px，固定的“展开 / 收起”与同一箭头 |
| 展开内容 | 独立层，16px 内间距，不撑高普通选项行 |
| 偏好词条 | 44px；长词悬停显示完整原文，来源正文保持完整 |
| 侧栏选中 | 一层选中背景，保留原有图标与文字，不加左侧竖线 |

**颜色沿用工作台主题变量，选中、悬停和焦点各有一致语义。** 色彩方案与浅深模式分开；主题快捷切换保留在主界面。较窄窗口允许纵向排布和说明换行，保持可操作性，不把高度一致强加到无法容纳的屏幕。

## 功能组织

**初始化规则属于个人工作区，设计组件属于公开源码。** 偏好弹窗只按已确认的配置归类；剩余原词显示为“原始词条 · 待整理”。空工作区、未知词条、已有偏好、长说明和恢复确认都必须检查。

**资料管理只提供完整备份、从备份恢复与历史修改恢复。** 未保存编辑的继续入口归属对应业务模块；恢复确认展示时间、模块和完整文件范围，不把版本哈希或内部事务 id 当作用户说明。
