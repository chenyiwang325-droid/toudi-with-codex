# 使用方案

**推荐复用自己的 Agent，以免费在线查阅开始使用；需要跨设备编辑时，优先采用同一托管平台。** GitHub 分发代码和文档，个人资料独立保存。工作台不要求购买模型 API、独立域名或额外的 Agent 服务。

## 当前如何选择

**当前零新增托管费用的完整用法是“Agent 环境中管理，Cloudflare 网站上查阅”。** 工作区中的完整工作台保留手动编辑与文件导入；发布的加密阅读站可在电脑和手机打开，电脑关机后仍可查阅上次已发布内容。阅读站不能写回工作区，更新只有在重新发布后才生效。

| 使用方式 | 当前状态 | 适合用途 | 费用边界 |
| --- | --- | --- | --- |
| **Agent 管理 + Cloudflare 加密阅读站** | 已实现，推荐起步 | 原工具处理信源与材料，完整工作台管理，网站跨设备查阅 | Pages 免费方案额度内无新增托管费；继续使用自己的 Agent。 |
| 完整在线 Python 实例 | 已实现，托管待实测 | 希望立即采用现有后端，在不同设备修改同一份资料 | 自有服务器按已有资源使用；新建 Render 实例有服务和磁盘费用。 |
| **Cloudflare 完整编辑版** | 方案阶段，尚未实现 | 希望网页管理与 Agent 同步共用一个免费托管平台 | 以 Workers Free + D1 免费额度为目标，须先验证运行限制和附件方案。 |

不需要在线阅读时，只使用完整工作台即可，无须注册托管账号。已有可用 Python 或容器服务器时，可以复用该服务器，不要求另购 Render。具体操作见[首次使用与部署](首次使用与部署.md)及[云端部署](云端部署.md)。

## 首次使用

**首次配置由用户提供资料和授权，具体环境与发布操作交给自己的 Agent。** 用户无需在工作台设置页反复填写本地路径或管理多个服务。

1. 从 GitHub 下载代码，提供自己的信源、简历、JD 或面试材料；无需复刻作者来源，也无需导入示例库。
2. 在常用 Agent 工具中粘贴 README 的接入说明，指定任务范围。Agent 读取流程契约，检查依赖、建立资料工作区并启动完整工作台。
3. 在完整工作台核对资料；可手动修改进度、标记与正文，也可通过规范文件导入新资料，操作范围见[手动使用](首次使用与部署.md#手动使用)。
4. 需要在线查阅时，指定自己的 Cloudflare 账号与 Pages 项目，保管解锁口令。Agent 构建并核对加密产物，只发布 `.stage` 白名单目录。
5. 收藏自己的 HTTPS 网址。以后让 Agent 完成任务并更新阅读站，自己打开网页查阅；首次登录或身份验证仍由账号所有者完成。

公开仓库只保存代码与说明；个人正文、附件、备份和凭据不提交到 GitHub。账号与发布授权通常只在首次配置或目标变化时处理，不作为每次业务任务的前置步骤。

## 日常协作

**每次任务沿用同一条保存与验收流程，用户只需说明要处理什么。** 阅读站与正式工作区各有明确用途，Agent 不从旧快照反向重建母本。

```mermaid
flowchart LR
  A[用户提供任务与材料] --> B[Agent 读取最新母本]
  B --> C[执行对应流程并校验]
  C --> D[保存到正式工作区]
  D --> E[需要时构建并发布加密阅读站]
  E --> F[核对实际网页与附件]
```

| 任务 | Agent 负责 | 用户操作 |
| --- | --- | --- |
| 更新投递记录 | 读取指定信源，核对日期与主体，保留标记，发布合格记录 | 提供可读信源，确认无法判断的事实。 |
| 面试准备 | 根据真实材料组织公司背景、JD 与问答，预检并导入 | 指定公司、岗位与准备重点。 |
| 岗位探查 | 分开整理事实、依据、判断与未核事项，登记报告 | 指定主体和关心的问题。 |
| 面试复盘 | 处理真实逐字稿，整理全场要点与必要改进，按场次导入 | 提供材料与场次；内化题库另按明确任务执行。 |
| 手动维护 | 后续任务读取最新手动修改，保留无关内容 | 在完整工作台编辑，或按文档维护规范文件。 |
| 在线查阅 | 在发布授权内构建、检查和更新加密站，返回实际网址 | 打开网址并解锁；阅读站显示最近一次成功发布。 |

只指定一个可写母本。Agent 任务失败时保留候选，发布失败时保留上次可用阅读站，并明确本次哪些内容尚未在线更新。任务不会自动变成网申、外部沟通或无人值守调度。

## 完整网页编辑的后续方案

**后续优先实现 Cloudflare 单平台编辑版，以免费额度为起点。** 前端资源与轻量接口由一个 Worker 提供，D1 保存投递记录、个人标记、偏好与资料正文；Agent 继续使用原有工具处理信源、研究、转写和文档导入。用户只管理一个托管账号，无需常驻本机服务来打开云端网页。

按 2026-10-03 核对的官方规则，Workers Free 包含每天 100,000 次动态请求，每次调用 CPU 上限为 10 ms；D1 免费额度包含每天 500 万行读取、10 万行写入，单数据库最多 500 MB，账号总计 5 GB。静态资源请求免费，仍受平台其他限制。额度在账号内共享；这支持个人轻量工作台的可行性判断，不代表本项目已通过性能验收。[Workers 计费](https://developers.cloudflare.com/workers/platform/pricing/)、[D1 计费](https://developers.cloudflare.com/d1/platform/pricing/)、[D1 限制](https://developers.cloudflare.com/d1/platform/limits/)

实现需要同时满足以下要求，不能只把现有 HTML 上传后称为完整在线版：

- **保留功能与格式。** 手动编辑、导入和 Agent 协作仍使用既有内容契约；Python 导入工具在 Agent 环境执行，接口只处理资料读取与写入。
- **控制请求成本。** 按模块加载、分页查询、建立索引并增量同步，不在每次打开时扫描或重写整库；登录与保存也必须满足免费 CPU 限制，不能通过弱化认证达到限制。
- **保留保存保护。** 网页和 Agent 共用同一份数据、稳定身份与版本检查；冲突保留草稿，批次校验失败不提交，备份可导出到自己的材料环境。
- **明确附件边界。** D1 单行或 BLOB 上限为 2 MB，不用它堆积原始录音和视频。优先复用现有加密静态附件方式，但正文版本、附件引用与发布恢复必须一并适配；需要跨设备编辑附件原件时再选择对象存储。

R2 有免费用量，但开通需要完成订阅结算流程，超出额度按用量收费，因此不作为默认必选项。[R2 开通说明](https://developers.cloudflare.com/r2/get-started/)、[R2 计费](https://developers.cloudflare.com/r2/pricing/)

保持 Free 方案时，超出动态请求或数据库额度会使相关请求失败；应提示并保留本地草稿，恢复后再同步，不自动升级付费。额度、网页打开速度、资料容量及账号内其他项目用量需要在真实部署后核对。[Workers 限制](https://developers.cloudflare.com/workers/platform/limits/)、[D1 超额规则](https://developers.cloudflare.com/d1/platform/pricing/)

## 实施顺序

**先验证免费编辑方案能覆盖实际任务，再把它设为默认在线部署入口。** 当前保持已有工作区与免费阅读站，不迁移正式母本，不新增付费实例。

1. 用隔离工作区验证 Worker 登录、D1 版本保存、Agent 增量同步与附件发布；测试读写、冲突、重启和恢复。
2. 在目标网络核对电脑与手机的登录、列表、正文和附件速度，统计 CPU、请求、数据库与附件用量。
3. 验证通过后提供可执行的 Cloudflare 部署入口、一次性接入说明和完整导出恢复流程，再核对用户资料的字段、身份与路径。
4. 迁移后将云端设为唯一可写母本，原目录留作回退；若免费条件无法满足明确需求，再由用户选择已有服务器或付费托管。

本页是使用选择与后续实现方案。当前可执行的免费发布方式是加密阅读站，完整 Cloudflare 编辑服务尚未提供部署入口。
