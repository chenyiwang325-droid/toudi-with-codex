# 云端部署

## 部署后的使用方式

**TouDi 在线版是一个由你自己托管的个人工作台。** 浏览器负责查阅和手动修改，服务将资料保存到持久工作区；投递 Agent 通过授权接口拉取资料、执行原有流程并同步结果。电脑关机不影响网站运行。

一个部署实例对应一个使用者。访问密码保护网页，独立的 Agent 凭据保护资料同步；网页不执行任意命令，也不调用默认模型。招聘信源、材料和协作任务由你提供。

## 在 Render 部署

**仓库已提供网页部署配置，平台会创建服务和持久磁盘。** 不需要在自己的电脑上启动服务。

1. 从 README 点击 **Deploy to Render**，登录你自己的 Render 账号。也可先 Fork 仓库，再从自己的仓库创建 Blueprint，平台会读取根目录的 `render.yaml`。
2. 设置 `TOUDI_PASSWORD`：用于网页登录，至少 16 个字符。会话密钥和 Agent 凭据由部署配置分别生成。
3. 核对服务和存储费用，再由你确认创建。配置选择带持久磁盘的服务；文件必须保存在挂载目录，才能在重启或更新后保留。
4. 部署成功后，打开平台提供的 HTTPS 网址，输入访问密码。页面从空工作区开始，提供自己的真实资料后即可使用。
5. 在设置中复制 Agent 接入说明，把信源、材料及本次任务交给自己的 Agent。按下文配置其授权环境。

Render 支持从仓库部署 Python 服务、提供 HTTPS 地址及持久磁盘；部署按钮会让用户审核并确认创建的服务。持久磁盘需要付费服务，实际费用以平台确认页面为准。[服务部署](https://render.com/docs/web-services)、[部署按钮](https://render.com/docs/deploy-to-render)、[持久磁盘](https://render.com/docs/disks)、[价格](https://render.com/pricing)。

部署配置关闭从作者仓库自动更新。更新时由实例所有者确认版本并手动部署；资料位于独立持久磁盘，不跟随代码仓库替换。带磁盘的服务更新会短暂中断访问。[平台更新规则](https://render.com/docs/deploys)。

## 必要配置

**这些配置在托管平台完成，工作台页面只负责日常使用。** 密码和密钥属于环境 Secret，不提交到 GitHub。

| 配置 | 作用 | 设置方式 |
| --- | --- | --- |
| `TOUDI_MODE=hosted` | 开启受保护的在线模式 | 部署配置已提供。 |
| `TOUDI_WORKSPACE` | 服务端持久资料目录 | 配置指向挂载目录，无需在网页填写本机路径。 |
| `TOUDI_PASSWORD` | 浏览器访问密码 | 由你设置，至少 16 字符。 |
| `TOUDI_SESSION_SECRET` | 签发浏览器会话 | 平台生成，至少 32 字符。 |
| `TOUDI_AGENT_TOKEN` | 允许你的 Agent 同步资料 | 平台单独生成，至少 32 字符；与访问密码不同。 |
| `TOUDI_PUBLIC_URL` | 实例的 HTTPS 地址 | Render 默认地址由平台自动提供；使用自定义域名时填自己的 HTTPS 源地址。 |
| `PORT` | 服务监听端口 | 托管平台提供。 |

访问密码或会话密钥缺失时，在线服务拒绝启动；未设置 Agent 凭据时，资料同步接口保持关闭，仍可手动使用。浏览器会话有效期为 12 小时，支持退出登录；修改会话密钥会使现有会话失效。Agent 凭据只放在你授权的工具环境中，可在托管平台单独更换。

## Agent 协作

**Agent 使用当前资料副本完成任务，再将变更同步回网站。** 网页与 Agent 共用同一套记录、准备、复盘和探查格式。

先将工作台网址设置为 Agent 环境中的 `TOUDI_REMOTE_URL`，将授权凭据设置为 `TOUDI_AGENT_TOKEN`。凭据从托管平台的 Secret 配置安全交给自己的 Agent 环境，不贴进公开文档或聊天记录。

在仓库目录中执行：

```sh
python3 app/脚本/remote_workspace.py pull --workspace ./runtime/cloud-work
export TOUDI_WORKSPACE="$PWD/runtime/cloud-work"
```

副本包含当前的规范投递记录、个人标记、通用准备、公司准备、复盘、探查目录和对应资料。Agent 按[流程协作](流程协作.md)处理本次任务，继续使用已有的预检、准备导入、复盘导入及探查校验工具。

完成后先查看范围，再提交：

```sh
python3 app/脚本/remote_workspace.py status --workspace ./runtime/cloud-work
python3 app/脚本/remote_workspace.py push --workspace ./runtime/cloud-work
```

同步只发送变更文件。服务验证每个文件的 SHA256 base，在同一资料锁内处理一批更改，保存恢复副本；版本冲突返回 409，整批不写入。失败时保留本地候选，另拉最新副本进行对账。同步工具不删除远程文件；需要删除条目时，按原模块流程更新对应 JSON 或目录，并保留无关内容。

大文件单个上限为 20 MiB，一次同步请求上限为 32 MiB、100 个文件；较大任务可通过重复 `--only 相对路径` 选择相关文件分批执行。空投递数组替换需显式使用 `--allow-empty-records`。API 不开放命令执行、代码目录、隐藏文件、口令或凭据。

## 手动使用

**手动编辑和 Agent 协作可以同时使用。** 在网页维护投递进度、收藏、适合与否、备注、通用准备及已有复盘，改动直接保存到云端工作区。

新增记录、公司准备、探查和复盘稿仍使用约定文件流程：先拉取副本，自行编辑并运行相应导入工具，再同步修改。具体入口见[手动使用](首次使用与部署.md#手动使用)。在线版保留这些操作方式，信源处理由自己的工具完成。

## 备份与更新

**个人资料与代码更新分开管理。** 平台持久磁盘用于持续保存；定期将云端资料拉取到独立备份目录，并保留平台磁盘快照。网页“个人标记与求职偏好”导出只备份标记与偏好，完整资料备份应使用资料拉取。

更换实例时，将核对过的完整资料副本推送到新实例；先读取新实例的当前版本，不复用旧实例的 base。新实例核验后再处理旧实例，避免丢失网页上的最新修改。源代码、资料副本、口令、密文和备份不混入公开仓库。

## 其他部署平台与 Cloudflare

**完整工作台可部署到支持 Python 或容器、HTTPS 和持久存储的云平台。** 仓库附带 Dockerfile；托管环境配置上表的变量，将持久卷挂载到 `TOUDI_WORKSPACE`，由平台提供 HTTPS 入口。Docker 默认资料目录为 `/var/lib/toudi`，运行用户为 UID 10001，挂载目录须对该用户可写。

Cloudflare 可用于域名、访问控制，或承载加密只读快照。现有 Python 文件服务不能直接作为 Pages 静态站点运行。若要将完整数据服务改成 Cloudflare 原生架构，需要增加 Workers API 和持久数据存储，并适配资料同步与附件；本次提供的是可托管现有后端的完整在线方式。Cloudflare Workers 官方支持静态资源与服务逻辑一同部署，[静态资源](https://developers.cloudflare.com/workers/static-assets/)和[Durable Objects 存储](https://developers.cloudflare.com/durable-objects/api/sqlite-storage-api/)可用于后续适配。

## 验证范围

在线模式已通过隔离实例验证登录、网页新增与保存、重新打开后的内容、Agent 拉取与同步、资料范围、版本冲突、批次失败恢复和服务重启后的文件保留。Render 配置与 Dockerfile 尚未经过真实托管部署验证，本仓库不替用户创建托管账号或付费服务。第一次实际部署后，确认自己网址上的登录、修改保存、重新打开后的数据和 Agent 同步结果。
