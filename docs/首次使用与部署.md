# 首次使用与部署

## 选择部署方式

**管理与编辑需要可写服务，用户与 Agent 共用工作区中的正式资料。** 当前可在自己的材料环境启动服务，或按[云端部署](云端部署.md)复用已有服务器。加密阅读站仅是附加查阅入口。各模块编辑现状见[编辑与保存](编辑与保存.md)，后续免费可写方案见[使用方案](使用方案.md)。本页提供当前已实现功能的操作步骤。

## 本地运行（可选）

下载仓库 ZIP，或：

```sh
git clone https://github.com/chenyiwang325-droid/toudi-workbench.git
cd toudi-workbench
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python3 run.py
```

访问 http://127.0.0.1:8327/ 。Python 3.10+，macOS/Linux；服务只监听 loopback，并校验 Host/Origin，无跨域开放。运行会创建空工作目录，不生成业务记录或示例库。所有模块可在空状态启动；资料可由你手工维护，也可交给自己的投递 Agent 按流程整理。直接双击 HTML 仅是浏览器缓存模式，正式可写使用本地服务。

只需本地页面时 Python 标准库足够；cryptography 用于快照加密。PDF 正文提取可选安装 Poppler 的 pdftotext（macOS `brew install poppler`；Debian/Ubuntu `sudo apt install poppler-utils`），未安装仍可读 PDF 原件。DOCX 文本解析使用标准库。前端没有包管理构建、远程字体或 CDN 依赖。

默认资料目录为仓库 runtime/，默认被忽略。可改为仓库外目录：

```sh
export TOUDI_WORKSPACE="$HOME/toudi-workspace"
export TOUDI_PORT=8327
python3 run.py
```

上述变量同样用于所有 Python 脚本。工作区是数据目录的父目录：`$TOUDI_WORKSPACE/投递数据/`、`面试准备/`、`岗位探查/`、`复盘/`。浏览器不能仅凭用户输入的本机路径读文件；文件访问由数据服务按当前准备稿引用与探查登记范围提供。在线工作台使用其云端工作区；单独的加密阅读版只读取快照，不连接本机。

## 给自己的 Agent 的接入话术

复制以下内容，补齐花括号中的用户输入即可。工具和模型由你自己的 Agent 环境提供；不需要作者的私有 skill。

> 请在我的本机维护 TouDi 工作台。仓库位置是 {下载目录}，工作区是 {资料目录}。先读仓库根 AGENTS.md、docs/流程协作.md 和 docs/内容与渲染契约.md。我的记录信源为 {网址/文件/API与可用读取工具}，准备素材为 {简历/JD/经历/材料目录}，本次只执行 {更新/探查/准备/复盘/内化/快照} 的 {明确范围}。请先确认无法可靠读取的信源、身份/日期缺口，生成规范候选，按当前版本和文件锁写入，保留无关标记及材料，验证实际页面。不要替我网申、联系他人或自动扩展下一流程。若我要求手机同步，Cloudflare 账号/项目/分支为 {我自己的目标}；先构建并核对只含加密产物的 .stage，再按我给出的发布授权部署，口令/token留本机且不进日志或仓库。不要把我的数据或密文提交到GitHub。

Agent 可检查已有环境并启动服务、处理指定信源和导入材料。用户负责提供可用信源/资料、判定无法确定的业务事实、完成需要本人身份的登录与授权，以及指定发布目标。本仓库不提供网页内模型连接或任意 shell 执行接口。

## 手动使用

**推荐Agent协作，不要求必须使用Agent。** 网页和规范文件/命令是两种不同入口，操作仍遵守同一内容与保存契约。

- 投递管理：网页可改进度、收藏、是否适合、待查、备注；详情中的字段编辑支持截止、录入、校招类型、岗位、地点、应届生与学历。设置中的备份只包含个人标记/偏好，不是原始记录导入。
- 通用准备：网页可新增分类，以及新增、编辑或删除条目；未保存草稿在当前页保留。整库JSON没有网页上传入口。
- 公司准备：自行编辑约定结构的Markdown后，运行 `python3 app/脚本/9_面试准备导入.py PATH --company "公司" --position "岗位"`。网页阅读，不编辑Markdown或上传新稿。
- 岗位探查：自行编写Markdown并登记 `岗位探查/探查目录.json`，运行 `python3 app/脚本/prospect_catalog.py --write-index` 校验；网页读取已登记报告，没有报告上传/正文编辑入口。
- 面试复盘：新增场次先编写约定Markdown，运行 `python3 app/脚本/6_复盘导入.py PATH --company "公司" --position "岗位" --round "轮次"`；已有场次可在网页编辑原答、分析、总结与弱项，删除场次。没有新稿上传或网页新增场次入口。

**新增原始投递记录使用规范数组发布命令。** 按[内容与渲染契约](内容与渲染契约.md)手工整理完整候选JSON，运行 `python3 app/脚本/publish_records.py CANDIDATE_JSON --base CURRENT_SHA`；首次工作区用 `--base missing`。已有文件的SHA可用Python标准库或系统SHA256工具计算。命令发布完整候选，须包含要保留的旧记录并核对身份/标记；网页没有原始记录新增/删除或数组上传入口。不要把标记备份当记录数组。

手工重导前读取最新母本、备份并核对目标id和无关范围。409或SHA变化时保留候选、重读差异，不覆盖较新更新。各任务的格式、预检与恢复方式见[流程协作](流程协作.md)。

## 生成加密手机版

在同一工作区环境中执行：

```sh
python3 app/脚本/10_手机版快照.py --set-pass
```

口令只写 `$TOUDI_WORKSPACE/投递数据/手机版/.passcode`（默认 runtime 下）。构建后 `.stage/` 仅包含 index.html 和加密 assets/*.bin；输入口令后在浏览器内解密，资料原件按需获取。阅读版只读，修改请回在线或本地的完整工作台。默认密文独立 bin；`--inline-payload` 提供兼容内嵌回退，PBKDF2 强度不变。首次口令自动生成也不在日志显示，请本机读取；忘记口令可重建，旧快照副本不会随工作区自动删除。

## 部署到自己的 Cloudflare Pages

GitHub 分发源码，Cloudflare 托管你自己的加密快照，两者独立。不要开启把整个仓库直接部署成个人资料站的自动构建。

安装 Node.js 22+，按 [Cloudflare Direct Upload 官方说明](https://developers.cloudflare.com/pages/get-started/direct-upload/)登录并建立自己的项目：

```sh
npx wrangler login
npx wrangler pages project create YOUR_PROJECT
npx wrangler pages deploy "$TOUDI_WORKSPACE/投递数据/手机版/.stage" --project-name YOUR_PROJECT --branch main
```

使用默认工作区时把路径替换为 `runtime/投递数据/手机版/.stage`。非 Git 工作区显式指定 branch；Direct Upload 项目不能原地改成 Git integration。凭据使用自己环境的登录状态或安全环境变量，不放仓库、命令文本或图片。部署前列出stage全部文件/字节/SHA，确认没有口令/token/明文；部署后核对生产别名、实际解锁、只读和附件。仅构建不自动发布；本仓库没有作者站点的默认目标。
