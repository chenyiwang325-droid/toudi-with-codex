# 首次使用与部署

## 选择使用方式

**普通用户优先安装桌面 App，打开即可管理同一个持久工作区。** 下载入口与安装步骤见[桌面安装与使用](桌面安装与使用.md)。本页保留源码开发/替代运行，以及可选加密静态查阅版的操作；已有 Python 托管见[云端部署](云端部署.md)。

## 本地运行（可选）

**以下步骤面向源码开发与替代运行，安装包用户无需安装这些依赖。**

下载仓库 ZIP，或：

```sh
git clone https://github.com/chenyiwang325-droid/toudi-with-codex.git
cd toudi-with-codex
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python3 run.py
```

访问 http://127.0.0.1:8327/ 。Python 3.10+，macOS/Linux；服务只监听 loopback，并校验 Host/Origin，无跨域开放。运行会创建空工作目录，不生成业务记录或示例库。所有模块可在空状态启动；资料可由你手工维护，也可交给自己的投递 Agent 按流程整理。直接双击 HTML 仅是浏览器缓存模式，正式可写使用本地服务。

只需本地页面时 Python 标准库足够；cryptography 用于快照加密。PDF 正文提取可选安装 Poppler 的 pdftotext（macOS `brew install poppler`；Debian/Ubuntu `sudo apt install poppler-utils`），未安装仍可读 PDF 原件。DOCX 文本解析使用标准库。前端没有包管理构建、远程字体或 CDN 依赖。

默认资料目录为仓库 runtime/，默认被忽略。可改为仓库外目录：

```sh
export TOUDI_WORKSPACE="$HOME/toudi-workspace"
export TOUDI_PORT=8327
python3 run.py
```

上述变量同样用于所有 Python 脚本。工作区是数据目录的父目录：`$TOUDI_WORKSPACE/投递数据/`、`面试准备/`、`岗位探查/`、`复盘/`。浏览器不能仅凭用户输入的本机路径读文件；文件访问由数据服务按当前准备稿引用与探查登记范围提供。在线工作台使用其云端工作区；单独的加密阅读版只读取快照，不连接本机。

## 手动使用

**四个业务模块通过管理入口维护同一份正式资料。** 新增、编辑、规范导入/导出及删除恢复的范围见[编辑与保存](编辑与保存.md)。公司准备使用 Markdown 母本，探查正文、目录与附件一致维护；所有导入先验证结构、稳定身份与引用。

**专用源码脚本继续保留。** 规范记录发布、准备和复盘 Markdown 导入、探查目录检查及其事实边界见[流程协作](流程协作.md)。公共管理 CLI 与这些脚本使用各自读取返回的版本，不混用 base。手工重导前读取最新母本、备份并核对无关范围。

## 生成加密手机版

在同一工作区环境中执行：

```sh
python3 app/脚本/10_手机版快照.py --set-pass
```

口令只写 `$TOUDI_WORKSPACE/投递数据/手机版/.passcode`（默认 runtime 下）。构建后 `.stage/` 仅包含 index.html 和加密 assets/*.bin；输入口令后在浏览器内解密，资料原件按需获取。阅读版只读，修改请回桌面正式工作区或明确选用的在线实例。默认密文独立 bin；`--inline-payload` 提供兼容内嵌回退，PBKDF2 强度不变。首次口令自动生成也不在日志显示，请本机读取；忘记口令可重建，旧快照副本不会随工作区自动删除。

## 部署到自己的 Cloudflare Pages

GitHub 分发源码，Cloudflare 托管你自己的加密快照，两者独立。不要开启把整个仓库直接部署成个人资料站的自动构建。

安装 Node.js 22+，按 [Cloudflare Direct Upload 官方说明](https://developers.cloudflare.com/pages/get-started/direct-upload/)登录并建立自己的项目：

```sh
npx wrangler login
npx wrangler pages project create YOUR_PROJECT
npx wrangler pages deploy "$TOUDI_WORKSPACE/投递数据/手机版/.stage" --project-name YOUR_PROJECT --branch main
```

使用默认工作区时把路径替换为 `runtime/投递数据/手机版/.stage`。非 Git 工作区显式指定 branch；Direct Upload 项目不能原地改成 Git integration。凭据使用自己环境的登录状态或安全环境变量，不放仓库、命令文本或图片。部署前列出stage全部文件/字节/SHA，确认没有口令/token/明文；部署后核对生产别名、实际解锁、只读和附件。仅构建不自动发布；本仓库没有作者站点的默认目标。

## 同工作区协作

**桌面 App、源码浏览器与 Agent 共用持久绑定的正式资料目录。** 显式 `TOUDI_WORKSPACE` 优先于连接配置，没有绑定时使用独立空工作区。已有资料按[原地接入流程](备份与迁移.md#原地接入已有工作区)执行预览、备份与基准核对、apply、check、bind 和 App 验收；命令见[Agent 接入](Agent接入.md#工作区绑定与原地接入)。

**业务资料更新保存后刷新即可显示，界面代码更新仍需构建 App。** 统一刷新先保护未保存草稿；App 关闭时 Agent 仍可使用 CLI 更新。原地接入保留正文、附件、题库和最新复盘，不要求重新导入全部资料。

**用户自己的信源处理流程继续保留，只衔接最终保存。** 日期核验、归并、身份迁移、锁、版本保护与附件验证仍属必要步骤；公共项目不内置作者私有抓取链，也不要求付费第三方服务。
