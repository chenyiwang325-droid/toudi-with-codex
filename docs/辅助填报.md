# Chrome 辅助填报

**TouDi 辅助填报在当前招聘网页检查、填写和核验表单，资料保存在插件本地。** 基本功能可以独立使用；启用 GPT-6 Luna 核对时，通过可选的本机连接工具使用现有 Codex 登录和额度。日常无需打开投递中控台 App 或启动 HTML 服务。

## 安装与首次设置

**先安装插件并导入自己的资料，需要 Luna 时再安装连接工具。** 当前为本地试用版本；公开 Release 中尚未包含时，可从源码构建，不把下载链接指向不存在的包。

1. 解压浏览器工具包，在 Chrome 的 `chrome://extensions` 开启开发者模式，点击“加载未打包的扩展程序”（部分版本显示为“加载已解压的扩展程序”），选择 `TouDi-filling` 文件夹，将插件固定到工具栏。
2. 打开插件的“资料与设置”，导入私人 JSON 资料包；没有资料包时，可以手动添加已确认字段。按个人、教育、实习／工作、项目和语言模块核对信息。
3. 若需要 Luna，运行包内的“TouDi 浏览器连接”安装程序一次。官方 Codex 客户端需要已安装并使用 ChatGPT 登录；已有有效登录会复用。
4. 在“资料与设置”点击“检查连接”。检查登录和模型目录不发起模型生成；成功调用才证明本次核对接通。

**本机连接工具由 Chrome 按需启动。** 工具仅接受连接检查和 GPT-6 Luna 字段匹配，不读取个人资料文件、不启动 HTTP 服务、不执行网页给出的命令。插件和连接工具不需要 API Key、云服务器或额外模型服务；Luna 消耗现有 Codex 可用额度。不可用、超时或额度受限时保留本地计划，不替换模型或自动转用 API。

当前打包脚本提供 macOS 安装程序；其他平台的安装、签名和实际浏览器验证以具体发布记录为准。macOS 试用包为临时签名，未进行正式公证。

## 日常填写

**在网申页面点击插件，核对一次计划后填写所选字段。** 插件只访问用户当前操作的页面，按表单标签、分组、记录提示与选项识别字段。

1. 选择本次简历口径，点击“识别当前页面”。
2. 查阅分组计划：可填写、已有一致、已有内容冲突、需选择记录、资料待补或需人工操作。
3. 有歧义时，点击“用 Luna 核对歧义”；也可在设置中启用识别后自动核对。明确字段先由本地规则处理，剩余歧义集中调用一次。
4. 必要时手动选择对应资料键。确认后点击“填写所选字段”；已有不同内容默认不选中，明确选择覆盖才修改。
5. 查阅逐项读回结果，再在招聘网页中保存草稿、上传附件、处理验证码与协议，最后由自己决定提交。

**填入成功与网站保存分别确认。** 核验一致证明当前控件保留了填写值，不能证明服务器已经保存；报告保留“网站保存未确认”，不把填写成功改成投递状态。

页面、资料或结构变化后需要重新识别，计划十分钟过期。写入后读回不一致、校验失败或字段消失，会报告具体未通过项；未执行字段仍列为待处理。

## 资料与更新

**私人资料只保存在当前 Chrome 的扩展本地存储中，原始文件继续作为 Agent 的资料母本。** 不使用 Chrome 云同步；重启浏览器保留资料，卸载插件会清除副本，迁移浏览器前应导出备份。

Agent 从已经确认的结构化信息生成资料包，用户首次导入。Agent 后续修改原始资料不会自动同步到插件，只需在资料发生变化时导入新版，无需每次投递重复导入。

插件提供分组查阅、搜索、字段新增／编辑／删除、别名、经历标识、适用口径、日期精度、GPA 满分、人工确认和填写规则维护，以及完整资料导出。保存采用版本检查，旧计划失效；导入替换插件副本之前会提醒保留本地编辑。

**不同经历与简历口径明确区分。** 通用口径包含个人、教育和语言信息；央国企／专业与 AI 产品口径分别限定适用经历。没有层级、单位或记录证据时，模型不能按卡片顺序猜测本科、硕士或实习归属；用户可明确选择已有事实。

**自然语言规则用于核对，不能自动视为已执行的约束。** 日期精度、记录归属、GPA 满分、长度、可选项与已有值保护由程序检查。新加规则若需要自动执行，必须实现对应检查；资料中的其他要求在计划确认时由用户核对。

## 与 Agent 协作

**Luna 只匹配资料键，个人事实由插件本地取值。** 请求包含待匹配字段标签、分组、选项，以及候选资料键、别名和必要的经历标签；不携带待填写值和网页现值。网页说明作为不可信数据处理，模型的 shell、浏览器、应用和插件工具关闭。

Agent 返回 `fieldId → factKey`，插件再次检查模块、明确语义、经历、日期、长度和选项。模型映射不能绕过检查；不明确的记录保持待选。也可复制匹配任务交给已有 Agent，然后导入返回的 JSON。

手动匹配可以记住，仅在网站、路径、结构和简历口径一致时复用；资料更新会重新核对。最近核验只保存状态等元信息，不持久保存实际填写值、网站现值和 URL 查询凭据。

**Agent 可以从现有工作区显式导出私人资料包。** 标准来源优先为 `填报资料/资料.json`，兼容已有 `网申信息库.json`。输出必须在公开源码仓库外；命令只导出，不修改母本。

```bash
python3 app/desktop_runtime.py filling --workspace /path/to/private-workspace export --output /path/to/private-profile.json
```

## 资料结构

**资料包保存已确认内容、记录关系和适用条件。** 根对象为 `schemaVersion: 1`，包含 `facts`、`rules`，以及可选的 `savedAt`、`name` 和 `supplements`。没有内置示例经历或作者私人资料。

| 字段 | 约定 |
| --- | --- |
| `key`、`label`、`value` | 稳定唯一键、字段名称与已确认内容 |
| `module` | `personal`、`education`、`internship`、`project`、`language` |
| `recordId`、`recordLabel`、`recordHint` | 同一段经历共用标识，名称和提示帮助区分层级、单位或项目 |
| `aliases` | 字段同义名称；户籍、生源地、籍贯与现居地各自维护 |
| `profiles` | `general`、`state`、`ai-product`；实习必须明确限定，不能混入通用口径 |
| `sensitive` | 计划隐藏完整值，完整内容仅在资料编辑或确认填写时使用 |
| `manual`、`companyScope` | 人工确认或公司专属资料，不自动泛化 |
| `precision` | `month` 或 `day`，不为只有年月的资料补日期 |
| `gpaScale` | 已确认的满分口径，未知时留空 |

## 支持范围与验证

**优先支持能可靠读取和核验的控件。** 原生输入框、文本域、日期、单选、下拉框及具有明确选项的简单 ARIA 选择器可处理；支持开放 Shadow DOM 和同源 iframe。

附件、验证码、协议、家庭成员和联系人保留人工操作。跨域 iframe、复杂级联和无语义控件需适配或人工处理；选项不唯一、日期缺日、GPA 口径不明、文本超长时不猜测或截断。

合成表单验收不能代表全部招聘网站适配。真实网站应分别检查识别覆盖、填写结果、网站保存及耗时；未实测前不宣称优于第三方工具。

## 开发构建

**浏览器工具与桌面 App 分开构建。** 扩展使用共享词汇、浏览器内的计划引擎和 DOM 填写引擎；本机工具只打包 Codex 连接模块。

```bash
python3 browser-tools/build.py --python /path/to/python-with-pyinstaller --output /path/to/browser-package
```

只构建扩展可加 `--skip-helper`。连接工具使用固定扩展 ID 注册 Chrome Native Messaging 通道；改变 manifest 的 key 或商店扩展 ID 时，需要一并更新允许来源并重新构建、注册。
