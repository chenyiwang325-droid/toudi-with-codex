# 隐私与公开发布

## 个人资料

**个人信息、求职记录、筛选偏好和招聘信源保存在用户自己的工作区。** 仓库提供通用程序、空记录模板与可配置的字段结构，不提供作者的真实简历、公司清单、筛选结果或来源地址。完整备份、填报资料导出包和加密查阅产物同样属于个人资料，不能提交到公开仓库或上传为 Release 附件。

## Agent 接入说明

**默认显示和复制的通用说明不带实际目录或实例地址。** 用户另行提供信源、材料及任务；本机路径采用占位符。桌面 App 的“复制本机流程”会加入当前工作区、资料工具和流程文档位置，仅用于用户已授权的本机 Agent。该操作不会包含填报值、职位偏好、来源配置或访问凭据。

**本机目录是运行时信息，不是公共示例。** 工作区位置可在数据设置中主动展开查看；公开截图、Issue、README 或远程聊天分享前应去除目录、账号、记录和来源信息。普通填报资料在本机保持可读，是否用于公开展示是另一个边界。

## 发布检查

**源码检查与安装包检查分别执行。** 源码检查拒绝个人目录、特定私有信源、凭据和数据文件，并要求记录模板与偏好默认值为空。桌面构建从 Git 可发布文件清单中暂存资源，排除缓存和私人工作区；Rust 编译路径使用通用前缀。安装包完成后继续检查文件、嵌套 ZIP 和压缩 Python 代码中的目录残留。

```sh
python3 tests/check_source.py
node tests/test_agent_privacy.cjs
python3 desktop/scripts/build.py --bundles app
```

**安装包检查失败时不能上传附件。** 构建脚本在完成包内检查前不会报告成功，使用旧运行组件时同样检查最终内容。重新包装 ZIP 或更换资源后应再次检查实际上传内容和校验和；仅检查源码不能证明安装附件符合公开边界。

**公开展示使用专门生成的虚构资料。** 不对真实简历或求职工作区直接截图，再依赖模糊效果隐藏；图片、动画帧、附件和文件元信息都要单独检查。发布检查只能控制当前仓库与附件，不能撤回他人已经保存的副本。
