# 日程安排

**日程用于安排投递、笔试、面试、准备与复盘，和其他资料保存在同一个工作区。** 从左侧“日程”进入，也可以在招聘记录详情顶部点击“添加到日历”，自动关联该条招聘记录。

## 添加与调整事项

**点击“新增事项”或日历中的日期，填写标题、类型与时间后保存。** 右侧编辑区可以补充公司、地点、会议链接、完整备注、优先级及相关准备或复盘材料。

1. 选择开始与结束日期、时间；全天事项只填写日期。
2. 时间未定时取消“安排日期”，保存为待安排事项；仅结束时间未定时取消“结束时间已确定”。
3. 点击“保存”。日程直接写入工作区，重新打开 App 仍可查看。
4. 在周历或月历中拖动事项改期，在周历中拖动事项底部调整结束时间。改期成功后显示“日期已更新”；未保存会恢复原位置并保留草稿。
5. 点击事项重新编辑，选择“已完成”保留历史；“取消事项”标记为已取消，在主列表与导出文件中隐藏，并在启用同步时取消对应的系统日程。

**周、月、列表分别用于安排时间、查看日期分布与逐项浏览。** 列表包含所有自建事项及未排期事项。窄屏默认使用列表，避免把长标题挤进过窄的周历列；用户仍可切换周历或月历。

**月历各周等高，周历的全天区不会随截止事项无限增长。** 月历按单元格可用空间折叠多余事项；周历全天区最多展示两层事项和一行“更多”。点击“+N 项”展开该日的完整列表，点击事项查看或编辑；标题在格内简洁显示，完整标题保留在展开列表和详情中。

## 招聘截止与材料关联

**招聘截止日期是招聘记录的只读投影，不能在日历里改成另一份日期。** 只有有效且明确到日的完整日期才显示为灰色全天事项，兼容横线、斜杠、点、中文年月日及连续数字格式；月份、“招满即止”和不明日期保留原文，不推定为月末。已排除或已通过、已拒绝、已截止的记录不显示截止投影。

**自建日程通过稳定的公司键和材料 ID 关联原资料。** 招聘记录更名时，公共保存入口迁移关联；原招聘记录删除后保留日程，显示“原招聘记录已移除”，不把它猜配给另一家公司。截止日期变化与 Agent 更新会自动刷新已打开的日程，正在编辑的内容和原保存版本保留。

**招聘详情和日程可以相互跳转。** 招聘详情的“日程安排”列出该记录的自建事项，点击即可回到日历编辑；截止事项详情及日程编辑区的“查看招聘详情”打开原招聘记录。点击“添加到日历”只打开编辑区，不直接创建事项。有明确截止日时预填为当天的全天投递事项；日期不明时保留待安排，用户选择类型、日期并保存后才写入日程。

## 本机日历

**macOS App 可以把选定事项同步到系统日历，无需第三方日历服务或付费 API。** 点击“日历连接”，主动授权日历访问，选择一个可写日历，再启用同步。各事项勾选“同步到本机日历”后才会写入；默认不连接、不申请权限、不写入系统日历。

**中控台是日程母本，系统日历是可选的显示与提醒入口。** 同一事项重复同步会更新已有事件；已完成事项保留，已取消事项取消绑定事件。系统日历中被外部修改或删除的事件返回原因，不自动覆盖或重建；在“日历连接 → 同步结果”查阅。停止同步会保留已经写入的系统事件。

**同步要求开始与结束时间已经确定，全天事项采用完整日期范围。** “日历提醒”仅通过系统日历或导出的日历文件生效，TouDi 本身不另外运行通知服务。提醒是否显示还取决于系统日历的通知设置。仅有开始时间、尚未排期的事项继续留在工作台。

**其他平台或浏览器可以导出 `.ics` 文件，手动导入日历。** 导出包含已排期的自建事项、完整备注和提醒；不包含已取消或未排期事项，也不建立自动同步。加密只读网页展示日程，编辑与导出在桌面 App 或可写工作区完成。

## 保存与 Agent 协作

**Agent 与界面通过公共模块 `schedule` 读取和保存同一份日程。** 正式文件为工作区中的 `投递数据/日程数据.json`；缺少文件时默认为空，首次保存创建，不附带作者的日程或示例数据。

1. 使用当前 App 资料工具运行 `read schedule`，读取完整资料与版本。
2. 依据用户确认的日期、事项和范围处理候选；不从投递状态推断面试时间，不给不明日期补造具体时间。
3. 对规范候选运行 `validate schedule candidate.json`，再把模块、原 `base`、操作与候选写入提交文件，运行 `commit payload.json`。
4. 重新 `read schedule`，核对标题、原文、时间范围、公司键与材料 ID。
5. App 自动显示已保存更新；日历连接启用后，打开日程或点击“立即同步”核对系统结果。

命令定位与提交文件方式见 [Agent 接入](Agent接入.md)。完整数据字段和日期规则见 [内容与渲染契约](内容与渲染契约.md#日程数据)。

**版本冲突保留双方，不自动覆盖。** 编辑草稿按工作区隔离，在浏览器与工作区镜像暂存；重新打开日程可恢复或舍弃草稿，也可导出候选对账。完整备份包含日程，恢复不含日程的新功能出现前的旧备份时保留当前日程。
